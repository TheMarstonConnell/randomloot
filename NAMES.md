# Name Generation

This document explains how Random Loot tool names are generated.

## Name Structure

Tool names follow this pattern:
```
[Adjective] [Prefix][Suffix]
```

Example: "Blazing Fytenblade" or "Frozen Halbedda"

## Base Names

### Prefixes

`Fyten`, `Fetter`, `Red`, `Tita`, `Ty`, `A`, `Demu`, `Tra`, `Yam`, `Hal`, `Wel`, `Hel`, `Min`, `Ju`, `Hwa`, `Kit`, `Kat`, `Kib`, `Lib`, `Sla`, `Sli`, `Slu`, `Effe`, `Edi`

### Suffixes

`blade`, `bedda`, `ayer`, `mit`, `miter`, `cer`, `gomme`, `mer`, `ber`, `wam`, `lam`, `lo`, `no`, `bo`, `low`, `bow`, `plow`, `cry`, `dry`, `wry`, `wrought`, `ought`, `ut`, `oot`, `uit`, `grey`, `sher`, `gy`, `shire`, `ord`, `yer`

## Temperature-Based Adjectives

The adjective is chosen based on the biome temperature where the tool is created.

### Hot Biomes (temp ≥ 1.0)

`Flaming`, `Scorched`, `Schorching`, `Red-Hot`, `Humid`, `Searing`, `Seared`, `Burning`, `Burnt`, `Molten`, `Glowing`, `Steamy`, `Sizzling`, `Fervent`, `Torrid`, `Roasted`, `Roasting`, `Blazing`, `Scalding`, `Ultrahot`, `White-Hot`, `Sweltering`, `Warm`, `Toasty`

### Cold Biomes (temp ≤ 0.1)

`Freezing`, `Chilly`, `Frozen`, `Artic`, `Frigid`, `Cool`, `Icy`, `Nippy`, `Chilled`, `Bone-Chilling`, `Snappy`, `Sub-Zero`, `Cryogenic`, `Brisk`, `Glacial`, `Polar`, `Ice-Cold`

### Temperate Biomes (0.1 < temp < 1.0)

`Temperate`, `Agreeable`, `Collected`, `Fair`, `Soft`, `Gentle`, `Mild`, `Pleasent`, `Mighty`, `Sturdy`, `Leafy`, `Modest`

### Rainy Weather

If it's raining when the tool is created, these adjectives are used instead:

`Wet`, `Damp`, `Gloomy`, `Sad`, `Drizzly`, `Stormy`, `Gray`, `Ghastly`, `Somber`, `Bleak`, `Dim`, `Murky`

## Forger Names

Each tool's lore mentions a forger. The forger name is based on biome temperature.

### Hot Biome Forgers

`Blazicus`, `Dante`, `Fyrus`, `Pyrok`, `Spaisee`, `Infernus`

### Cold Biome Forgers

`Boreas`, `Borias`, `Frostis`, `Wintor`, `Icis`, `Burr`

### Temperate Biome Forgers

`Heartha`, `Trunken`, `Plenta`, `Lushious`, `Ivern`, `Soummar`

## Example

A tool created in a desert (hot biome) might be named:
- **"Scorched Kitmer"** - forged by Blazicus

A tool created in a snowy tundra (cold biome) might be named:
- **"Frigid Halwam"** - forged by Boreas
